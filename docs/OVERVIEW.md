# Ocoopa 舆情监控 Agent · 项目简介

> 面向非技术读者(管理层/法务/PR)的总览。技术细节见 [README](../README.md),运维细节见 [OPERATIONS](OPERATIONS.md),召回事实基线见 [CURRENT_RECALL_26-659](CURRENT_RECALL_26-659.md)。

## 一句话
一个 7×24 小时自动盯梢 Ocoopa 全网舆情的系统:实时发现起火/致死/诉讼/召回等高危信号,第一时间推送到钉钉群,每天自动生成中文日报,并为 **CPSC 26-659 召回**提供专项台账与人工复核工作台。

## 当前形势(已从"预警"进入"处置")
项目启动时舆情尚在早期窗口;**2026-07-30,CPSC 正式发布召回 26-659**,情况已升级为公开的重大产品安全事件:

- 约 **150 万件**充电暖手宝被召回,涉及 7 个型号
- 官方通报:**1,480 起过热、15 起火灾、350 起烧伤,1 名 83 岁消费者死亡**
- 销售渠道/期间:Amazon、OCOOPA.com、Walmart.com,2018-09 至 2026-05

因此系统的价值重心也随之转移:从"抢在引爆前发现"变成 **"完整、可追溯地跟踪召回传播,并区分哪些是新增实质信号、哪些只是既有事实的转载"**。

## 它怎么工作(四步)
1. **抓取**——三条车道,只抓公开、合规内容:
   - **高敏(每 15 分钟)**:Google News、CPSC 官方召回库、律师导流站(集体诉讼招募)、Reddit 公开检索
   - **常规(每小时)**:商业搜索/新闻 API,并对公开社媒页面(TikTok/Instagram/Facebook/YouTube/X/论坛/评论页)做站点限定发现
   - **持牌社媒(每 5 分钟,可选)**:Brandwatch 只读试点,凭据齐全时才启用
2. **分析**:用大模型(DeepSeek,数据不出境)判定情感、风险等级(红/黄/绿)、分类,生成中文摘要,并校验每条结论能否回溯到原文。
3. **汇总**:每天自动生成中文日报推送钉钉;召回相关内容额外进入专项台账。
4. **告警**:红色高危**实时**推钉钉并 @ 负责人;其余按 routine 同步,不打扰。

## 四条已落实的"安全底线"
- **防漏报**:核心信号 15 分钟内捕捉;抓取源"失联"会自动告警;红色告警超 30 分钟无人处理会自动再提醒;所有推送先落库再发送,失败自动重试,不会丢消息。
- **防误报刷屏**:同一事件被多家媒体转载时只推一条;同一新闻稿在不同站点/账号的同步发布归入同一"传播簇";团队可一键标记"确认/误报/静音",并支持批量处理。
- **防造假(法务可用)**:每条结论强制绑定原始链接;模型只能基于原文、不得编造;证据校验不通过的显式标注"需人工核实",绝不当作既成事实。召回事实以人工核验的基线文件为准,**搜索摘要、社媒转述、模型生成内容一律不得升级为已确认事实**。
- **不夸大既有事实**:已知召回的普通转载登记为"新闻转载/社媒扩散",**不会**被当成新增伤亡或起火;只有第一人称事故陈述、新的监管/法律动作或传播突增才会升级告警。

## 合规边界
只做内部监控与告警,**绝不自动对外发布、绝不自动回复**——系统中不存在发帖、回复、点赞、隐藏或删除的任何接口。只抓公开内容,不登录、不绕过反爬、不抓私密账号或评论正文,遵守各平台规则。人工发现需要处置的评论后,回到复核台登记,由人决定动作。

## 配套工具
- **钉钉群**:实时红色告警 + 每日中文日报 + 召回同步。
- **网页复核台**:非技术同事在浏览器里处理"待处置队列",标记确认/误报/静音,登记人工介入状态(仅监测/建议回应/升级 PR 法务等),支持批量操作。登录走口令 + 会话 Cookie。
- **分析看板**:发布量与发现量双走线、平台趋势、跨平台扩散、议题归纳、传播角色与覆盖延迟矩阵,可逐层下钻到原文证据。
- **召回专项台账 + CSV 导出**:给法务做可追溯报告。

## 当前状态与边界
- ✅ 已在云端(Railway)稳定运行:scheduler 与 web 两个服务 + 托管 PostgreSQL,长期留存。
- ⏳ **仍是有人盯的试运行**:建议每日检查源健康、未投递队列、召回台账与日报,不应作为完全无人值守系统。
- ⚠️ **覆盖度必须诚实解读**:Facebook、Instagram、TikTok 的非官方账号内容并非全量;**某平台"零记录"只代表当前数据源未发现,不能解释为该平台没有讨论。**
- ⚠️ 抓取以标题和公开摘要为主,不等同于全文归档;重要红色内容仍需人工打开原文复核。
- ⚠️ 分析结论基于当前收录与机器分类,**不替代法务的事实认定**。
