# OCOOPA 召回 26-659 当前事实基线

状态：`CONFIRMED_OFFICIAL`
最后人工核验：2026-07-31

## 权威来源

- CPSC Recall 26-659:
  https://www.cpsc.gov/Recalls/2026/OCOOPA-Direct-Recalls-1-5-Million-Rechargeable-Hand-Warmers-Due-to-Risk-of-Serious-Injury-or-Death-from-Fire-and-Burn-Hazards-One-Death-Reported-Imported-by-Shenzhen-Street-Cat-Technology
- OCOOPA 官方召回页:
  https://www.ocoopa.com/pages/product-recalls

## 已确认事实

- 发布时间：2026-07-30。
- 数量：约 150 万件充电暖手宝。
- 受影响型号：`UT3053`、`UT3056`、`ZLS-118`、`ZLS-118S`、`ZLS-118D`、`H01`、`H01(PD)`。
- 风险：火灾和烧伤危险，可能造成严重伤害或死亡。
- 已报告事件：1,480 起过热报告、15 起火灾、350 起烧伤；另报告 1 名 83 岁消费者死亡。
- 销售渠道/期间：Amazon、OCOOPA.com、Walmart.com，2018-09 至 2026-05。
- 处理方式：消费者应立即停止使用，并按官方召回页流程申请退款。
- 官方召回邮箱：`ocooparecalls@ocoopa.cc`。
